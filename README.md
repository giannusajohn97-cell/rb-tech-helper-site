# Rancho Bernardo Tech Helper Website

This is a simple static website built for GitHub and Cloudflare Pages.

## Files
- `index.html` = main website page
- `styles.css` = site design and layout
- `script.js` = mobile menu and footer year
- `assets/logo.png` = logo file
- `assets/hero-tech-setup.png` = main hero image
- `assets/service-visit.png` = secondary image

## How to customize
### Change the logo
Replace `assets/logo.png` with your logo file.

### Change the photos
Replace:
- `assets/hero-tech-setup.png`
- `assets/service-visit.png`

Keep the same file names unless you also update the image paths in `index.html`.

### Change text
Open `index.html` and edit the wording inside each section.

### Change colors
Open `styles.css` and edit the color values under `:root`.

## Deploy with Cloudflare Pages
1. Create a GitHub repository.
2. Upload all files in this folder.
3. In Cloudflare Pages, connect your GitHub account.
4. Select this repository.
5. Use these settings:
   - Framework preset: `None`
   - Build command: leave blank
   - Build output directory: `/`
6. Deploy.
